AvatarVault 手机端（安卓）
====================================

一、安装
1. 把 AvatarVault-Mobile-0.2.8.apk 传到手机（微信/QQ/数据线都行）。
2. 点开安装，系统会提示「未知来源/未备案应用」，允许安装即可。
   （安装包没上应用商店，也没有签名证书背书，提示是正常的。）
3. 桌面会出现 AvatarVault 图标，名字和电脑端一样。
4. 升级安装请直接覆盖安装，不要先卸载——卸载会把手机素材库一起删掉。
   本安装包使用固定签名，可以覆盖升级。

二、手机端能干什么
- 把手机里的 .unitypackage / .zip / 其它素材加进「手机素材库」：
  右下角 ＋ → 选文件（可多选）。
- 自动识别成 素体 / 服装 / 妆容 / 道具 / 着色球，识别错了在详情里手动改。
- 自动统计：资产数、材质球、贴图、Prefab、预估显存、文件体积。
- 加示意图：详情里缩略条最后那个「＋」，从相册选图（会自动压到 1200px 以内）。
- 删示意图：每张缩略图右上角有红色小「×」，点它确认后只删这一张图，
  素材原件不动；删掉第一张（封面）会自动顺延到下一张，全删完就显示「无示意图」。
- 标签、备注、收藏、搜索，和电脑端一样。
- 删除：详情里点「删除」，会弹 App 内确认框。
- 手机端不拖拽（手机没有 Unity），它的价值是：随手收素材 + 打包带走。

三、导出给电脑（重点）
右上角「导出给电脑」：
1. 程序把 手机素材库 打成 zip（结构就是电脑端的备份格式：
   index.json + orig/原件 + prev/示意图）。
2. 系统弹出保存位置，选「下载」最省事。
3. 把这个 zip 传到电脑（数据线 / 网盘 / 微信文件传输助手）。
4. 电脑端 AvatarVault：右上角「库 ▾ → 从备份导入」→ 选「zip 文件」→ 挑这个 zip。
5. 导入后原件、示意图、标签、备注、统计数字全部带过去，卡片可以直接拖进 Unity。

注意：如果电脑库里已经有同名/同 id 的资产，导入时会跳过不覆盖（避免重复占空间）。

四、数据存在哪
- 安卓私有目录 files/vault：index.json + orig/ + prev/。
- 卸载 App 会一起删掉，所以记得先把重要素材「导出给电脑」。
- App 不联网、不上传任何东西，纯本地。

五、常见问题
- 选了 .unitypackage 但统计是 0？老版本系统 WebView（低于 Chrome 80）不支持流式解压，
  素材照样能存能导出，只是识别不出内部文件数；升级「Android System WebView」可解决。
- 导出很慢？素材包普遍几百 MB，压 zip 要时间，进度用系统提示条看。
- 安装时提示「应用未备案 / 未知来源」：本包没有上架，允许安装即可。

六、类目自定义
- 类目条最右边有「＋ 类目」，点它新建自己的类目（最多 12 个字）。
- 长按任意类目 → 底部弹出「上移 / 下移 / 重命名 / 删除这个类目」；
  删除时该类目下的素材会移到「未分类」，文件不动；「未分类」不能删。
- 类目随 index.json 保存：手机新建的类目，导出的备份在电脑「导入备份」时会自动补上，
  不会掉进未分类。电脑端新建的类目同理。
