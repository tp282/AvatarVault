AvatarVault 使用说明
====================

版本：PC 正式版 0.3.0 / 手机端 0.2.8
适用：VRChat 改模素材（.unitypackage / .zip / 散文件 / 文件夹）


一、这是什么
------------
把散落在硬盘里的改模素材收进一个本地库，按类目浏览、检索、成套管理，
再直接从库里拖进 Unity 的 Project 窗口。

它只管「库」，不管「装配」：骨骼重绑、材质迁移、性能校验这些仍然需要
Unity 编辑器插件来做。


二、两个版本怎么选
------------------
- PC 正式版（AvatarVault.exe，解压约 300MB）：功能最全，推荐日常使用。
- 手机端（AvatarVault-Mobile.apk，37KB）：随手收素材 + 打包带回电脑，不能拖进 Unity。

两端共用同一套库格式，可以指向同一个库目录。


三、PC 正式版怎么用
------------------
1. 解压
   把整个 AvatarVault 文件夹解压出来，不要只单独拷走 exe。
   双击 AvatarVault.exe 启动。
   首次运行 Windows 可能弹「Windows 已保护你的电脑」，点「更多信息 → 仍要运行」
   即可——程序没有做代码签名，这是系统对未知发布者的常规提示。

2. 第一次启动：选库目录
   程序会让你给素材库选一个存放位置。库里的原件副本、示意图、索引都放这个目录。
   素材包普遍很大，建议选一个空间充足的盘（不是系统盘更好）。
   之后想换：右上角「库 ▾ → 库位置…」。
   注意：换库位置不会自动搬走已有资产。

3. 添加资产
   - 点「＋ 添加资产」选择文件；或直接把 .unitypackage / .zip / 文件夹拖进窗口。
   - 支持 .unitypackage、.zip；.rar / .7z 会按普通文件收进库；
     单个 .fbx / .prefab / .mat / 图片也可以直接入库。
   - 同一个文件重复拖入会按 SHA-256 自动跳过，不会占两份空间。
   - 文件夹入库是「引用」模式：只记录原路径，不复制文件，也不能拖出。

4. 分类与整理
   - 自动识别为：素体 / 服装 / 妆容 / 道具 / 着色球 / 未分类；识别错了在详情里手动改。
   - 侧栏「类目 ＋」可以新建自己的类目（最多 12 个字）。
     右键类目可以重命名、上移 / 下移、删除这个类目；
     删除时该类目下的素材会移到「未分类」，文件不动；「未分类」不能删。
   - 详情里可以改名称、加标签、写备注、收藏。
     顶部搜索框按名称 / 标签 / 备注搜索。
   - 顶部「大图 / 紧凑 / 列表」可切换素材显示方式；窗口宽度变化时三栏会自动收窄，
     素材区和右侧详情栏都可以用鼠标滚轮上下滚动。
   - 备注里贴 BOOTH 商品链接（booth.pm/.../items/数字），离开备注框后会自动读取
     商品名和首图；没有链接就跳过，不影响备注保存。自己手动改过的名称不会被覆盖。
   - 套装用来整合一个项目要用的资源：可以新建空套装，也可以选中素材直接带入。
     套装视图里能添加/移出选中、前移/后移成员、写说明；成员按套装顺序显示。
     侧栏套装或套装头的「整套拖出」可以一次拖多个文件到 Unity；「导出文件夹」按类目分目录并附清单。

4.1 堆叠与合并卡（PC 0.2.8 起）
   - 在「全部资产 / 类目」视图里，Ctrl 点选 2 张以上同类目的卡片，右键其中一张，
     选「堆叠选中的 N 张」。跨类目不能堆叠。
   - 堆叠卡显示第一张封面和张数；点击原地展开，点「收起」合回去；右键可「解散堆叠」。
   - 堆叠会按库目录保存在程序自己的本地设置里（不写库的 index.json）；关闭软件再打开
     仍然保留，点「解散堆叠」才消失。展开/收起状态不持久，重启后默认折叠。
     换电脑、换库目录或清理程序设置后，堆叠分组不会跟着走。素材本身不受影响。
   - 展开后点「合并为 ZIP」，或右键堆叠卡选「合并为 ZIP 卡片」：把成员打成一个 zip，
     变成一张「合集卡」。原卡只隐藏、不删除，文件仍在库里。
   - 合并卡右键「还原原卡」可撤销合并，恢复原来的卡片；删除合并卡也会先还原原卡。
   - 合并卡本身是普通 zip 卡，可以像其他 zip 素材一样拖出；显存/材质等按成员汇总。
   - 这是 PC 端功能；手机端暂不显示堆叠/合并卡。

4.2 批量整理与性能（PC 0.3.0 起）
   - 连选：Ctrl 点选单张，Shift 点选一段连续区间，Ctrl+A 全选当前筛选结果。
   - Delete / Backspace 删除选中项；右键选中卡片可以「批量改类目」「批量加标签」「批量删除」。
   - 批量删除合并卡会先还原原卡；只删库内副本，原文件不动。
   - 封面改成了多档 WebP 缓存（32 / 320 / 640 / 1280），原图仍原样保留；
     上千条素材滚动时只渲染屏幕附近的几十张卡片，不再一次创建整墙 DOM。
   - 索引改为主进程常驻 + 追加日志 + 后台快照：改名、收藏、拖出等操作不再每次都
     全量写 index.json，退出/导入/导出前会强制落盘；异常退出后下次启动会重放日志。
   - 入库、补统计、合并等重活放到后台线程，界面不会因为一个大包卡住。

5. 示意图
   - 详情页缩略条最后的「＋」可以导入本地图片（可多选）；
     选中素材后直接按 Ctrl+V 可以粘贴剪贴板截图。
   - 每张示意图右上角有红色「×」，确认后只删这一张图，素材原件不动。
   - 程序不显示 .unitypackage 自带的预览图，封面只认你自己加的示意图。

6. 拖进 Unity
   - 在素材卡片上按住鼠标，直接拖到 Unity 的 Project 面板松开，文件就进工程了。
   - 文件夹引用、原件已丢失的条目不能拖，程序会给出提示。

7. 「库 ▾」菜单
   - 库位置…：切换库目录（不搬旧数据）
   - 打开库目录：在资源管理器里打开库文件夹
   - 导出整库（搬去另一台电脑）：打包成单个 zip 或文件夹
   - 从备份导入：选 zip 或备份文件夹，合并进当前库；按 id 去重，只增不覆盖


四、手机端
----------
- 安装：把 APK 传到手机点开安装，系统提示「未知来源」时允许即可。
- 能做什么：加素材、自动分类、统计、加示意图、标签 / 备注 / 收藏 / 搜索、
  删素材、自定义类目、导出整库 zip。
- 导出给电脑：
  右上角「导出给电脑」→ 选保存位置 → 把 zip 传回电脑 →
  电脑端「库 ▾ → 从备份导入」→ 选「zip 文件」。
  原件、示意图、标签、备注都会保留；显存等统计电脑端会按原件重新算一遍。
- 数据存在安卓私有目录 files/vault；卸载 App 会一起删除，重要素材先导出。
- 手机端不联网、不上传任何东西，纯本地。


五、库结构和备份
----------------
<库根>/index.json     索引：类目、素材条目、套装
<库根>/orig/<id>/     原件副本
<库根>/prev/<id>/     示意图

- 电脑端 id 是文件 SHA-256 的前 12 位；手机端 id 以 m 开头。导入时按 id 去重。
- index.json 里的原件路径是相对库根的（orig/<id>/文件名），整个库目录可以整体搬走或换盘。
- 备份 = 整个库目录，或者「导出整库」生成的 zip；导入时会按新电脑的库目录自动重写路径。
- **0.3.0 可以导入 0.2.8（以及更早 PC/手机端）导出的备份**：旧备份里的绝对路径、
  缺失 stats、旧示意图名、旧类目和套装都会自动兼容；按 id 去重，只增不覆盖。
- 0.3.0 新增的 `.avatarvault/` 只存运行日志和快照序号，不会打进「导出整库」的备份里；
  旧版程序也能直接读 0.3.0 导出的 `index.json + orig + prev`。
- 文件夹引用（refOnly）记录的是原电脑的绝对路径，换设备后需要重新入库或重新指定。
- 电脑端配置在 %APPDATA%\AvatarVault\config.json，只记录库路径和堆叠分组。
- 恢复：新机器装好程序 → 选库目录 → 「从备份导入」。


六、常见问题
------------
- 首次运行被 SmartScreen 拦：未签名程序的正常提示，点「更多信息 → 仍要运行」。
- 拖进 Unity 没反应：确认是拖到 Project 面板；文件夹引用不能拖；
  留意是否提示「原件已丢失」。
- 文件夹引用换电脑后失效：引用的是原路径，需要重新入库或重新指定路径。
- 导出 zip 超过 4GB：程序会自动改为文件夹导出（zip 写入不支持 ZIP64）。
- 手机端统计为 0 / 电脑导入后显存显示「—」：老系统 WebView 低于 Chrome 80
  不支持流式解压，手机端可能算不出统计；电脑端导入时会按原件重新统计并写回 index.json。
  也可以在电脑端详情页选中该条目，程序会自动补算一次；重复导入同一个备份时，
  已存在条目也会顺手补算。
- 自动分类不准：识别只看路径关键词，手动改一次即可；自定义类目只能手动指定。


七、卸载
--------
- PC 绿色版：直接删除程序文件夹。库目录要单独删，程序不会自动清。
- 手机端：卸载会删掉 files/vault，先「导出给电脑」。
